# AI Hub Model

This is a website where you can see different AI models and add them to your cart. I made it using React and Vite.

## 🚀 Live Demo

Check it out here: [ai-hub-frontier.netlify.app](https://ai-hub-frontier.netlify.app)

## What Can You Do?

- 🤖 See lots of different AI models
- 🛒 Add models you like to your cart
- 🎨 Nice looking website that works on phones too
- ⚡ Super fast!
- 📱 Works on mobile phones

## What Did I Use?

- **React** - For making the website interactive
- **Vite** - To make the code run fast
- **CSS** - To make it look nice
- **JavaScript** - The coding language

## Folder Structure

```
src/

│   ├── Footer.jsx      - The footer at the bottom
│   ├── ModelCard.jsx   - Each model card
│   ├── Models.jsx      - All the models together
│   └── Navbar.jsx      - The top menu bar
├── App.jsx             - Main file
├── main.jsx            - Where everything starts

└── index.css           - General styling
```

## How to Run It

### What You Need

- Node.js installed
- npm (comes with Node)

### Steps

1. Get the code:
```bash
git clone <repository-url>
cd AI-PROJECT
```

2. Install packages:
```bash
npm install
```

3. Run the website:
```bash
npm run dev
```

It will open at `http://localhost:5173`

### Make It for Real Websites

```bash
npm run build
```

### Check the Final Version

```bash
npm run preview
```

## Commands I Use

- `npm run dev` - Start coding (with hot reload)
- `npm run build` - Make it ready for the internet
- `npm run preview` - See how it looks when it's live
- `npm run lint` - Check if the code is written nicely
