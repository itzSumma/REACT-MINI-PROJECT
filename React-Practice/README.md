# 🌍 The Countries I Visited (Project 2)

Hi there! 👋  
This is my **second React project**. I made it to **keep track of countries I’ve visited** and their flags.  
I wanted to practice **React state, components, props, and CSS** while making something fun and interactive.

---

## 🌐 Live Demo

Check it out here: [The Countries I Visited](https://the-country-i-visited.netlify.app)

---

## ✨ What You Can Do

- See a list of countries with info:
  - Name, Capital, Region
  - Population, Area, Languages
  - Flag image
- Mark a country as **Visited** ✅
- Add a country’s **flag to a visited flags section** 🏳️
- See totals for:
  - Countries you’ve visited
  - Flags you’ve added
- All cards are nicely laid out with **CSS Grid & Flexbox**

---

## 🛠 Tech I Used

- **React** (useState, props, components)  
- **CSS** for styling  
- **Vite** to start the project  
- **Netlify** to deploy it
